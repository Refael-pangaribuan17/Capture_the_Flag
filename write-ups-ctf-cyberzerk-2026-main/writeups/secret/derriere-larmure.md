# Derrière l'Armure

Secret · 500 points · Créé par [@PercevalFox](https://github.com/PercevalFox)

C'est un easter egg à 500 points fixes. Le challenge est invisible tant qu'on n'a pas cliqué trois fois sur le mot « armure »
de la page `/prologue` (menu « Opération CyberZerk »). À ce moment le serveur le débloque pour le compte connecté et affiche
le flag.

La description est un message de soutien sur la santé émotionnelle des hommes.

**Flag :** `CyberZerk{le_masque_tombe_et_les_cheaters_tombent_aussi}`
