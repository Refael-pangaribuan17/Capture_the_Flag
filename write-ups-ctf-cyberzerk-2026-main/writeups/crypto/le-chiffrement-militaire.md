# Le Chiffrement Militaire

Cryptographie · 100 points · Créé par [@PercevalFox](https://github.com/PercevalFox)

C'est du base64, trois fois de suite :

```bash
echo TOKEN | base64 -d | base64 -d | base64 -d
```

`TOKEN` est la chaîne donnée dans l'énoncé. Le nom du flag dit déjà tout : base64 n'est pas du chiffrement.
